# Sadak Saathi website
Static website (Hindi + English). Host on GitHub Pages: Settings > Pages > Deploy from branch > main > / (root).
Edit only config.js to connect it to your live app.
Upload everything in this folder, including the img folder (3D photos, depth maps, illustrations). About 80 files in all.
The optional camera head-tracking button loads its face tracker from cdn.jsdelivr.net and storage.googleapis.com.
